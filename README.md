## Base de datos
ecommerceClientesDB

## Colección
clientes

## Objetivo

Desarrollar una base de datos orientada a clientes utilizando MongoDB y estructuras de arreglos para almacenar:

- Múltiples direcciones
- Productos favoritos
- Métodos de pago
- Compras
- Historial de navegación

## Requisitos implementados

- 5000 clientes
- 3 direcciones por cliente
- 10 productos favoritos
- 5 métodos de pago
- 20 compras
- 30 registros de navegación

## Consultas realizadas

1. Buscar clientes con producto favorito específico.
2. Buscar clientes con compras mayores a $300.
3. Contar clientes con más de 10 compras.
4. Agregar producto favorito.
5. Eliminar producto favorito.
6. Evitar elementos duplicados utilizando $addToSet.
